# architecture-medikamente

Проектная работа 10 спринта курса «Архитектура программного обеспечения: продвинутый уровень» от Яндекс.Практикума.

Кейс: компания «Медикаменте» - сеть медицинских услуг, которая пока ведёт учёт пациентов, платежей и товарно-материальных ценностей вручную в Excel и 1С. Компания открывает новые филиалы и ожидает кратный рост числа клиентов, поэтому задача - спроектировать архитектуру, которая обеспечит безопасную и масштабируемую работу с конфиденциальными данными пациентов.
