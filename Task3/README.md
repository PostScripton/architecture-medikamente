# Задание 3. Оценка Data Encryption at Rest and In Transit

## Классификация данных и стратегия защиты

[data_protection_strategy.md](data_protection_strategy.md) содержит классификацию данных компании по состоянию (at rest / in transit), уровню чувствительности и профилю риска: PII, специальная категория данных (медицинские карты, анализы, диагнозы), платёжные данные, кадровые и бухгалтерские данные, аутентификационные данные, внутренние операционные данные, данные аудита и мониторинга.

Для каждого класса данных приведено обоснование необходимости защиты и конкретные инструменты: TLS 1.3 для передачи, шифрование на уровне базы данных и приложения, KMS, токенизация платёжных данных, шифрование дисков, маскирование в интерфейсах и хранение только хешей паролей.

Отдельно описан автоматизированный контроль: CI Data-Guard проверяет релизы на корректную работу с тегированными данными, DLP-система отслеживает попытки выгрузки чувствительных данных, SIEM собирает логи доступа и обнаруживает нетипичные действия пользователей, KMS автоматически ротирует ключи шифрования.

## Реестр средств защиты данных

[protection_tools_registry.md](protection_tools_registry.md) содержит перечень программных средств (TLS, KMS, шифрование СУБД, шифрование дисков, DLP, SIEM, Data Catalog & Tagging, CI Data-Guard, IAM, Anonymization Pipeline) и аппаратных средств (HSM, диски с самошифрованием, аппаратный межсетевой экран, ККМ с шифрованным каналом связи), которые обеспечивают защиту данных компании.
